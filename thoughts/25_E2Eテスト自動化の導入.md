## Claudeの思考

### 実現可能性の判断

好条件が揃っていた：
- `playwright` が既に devDependencies に存在（マップマッチング等の別用途で導入済み）
- Vite の dev/preview サーバーで完結するクライアントオンリー SPA。バックエンド不要
- 外部依存は地理院タイル・標高 API・ジオコーディング API のみで、いずれも `page.route()` でモック可能

一方、地図キャンバス（Leaflet / MapLibre）上のポイント操作は canvas 描画のため
DOM セレクタが効かない。ここは横展開時の注意点として認識し、スモークでは
「タイルと独立した SVG レイヤー（polyline = `path.leaflet-interactive`）の存在」で
描画確認する方針にした。

### スモーク1本のスコープ

このアプリのコア価値＝「読み込み → 編集 → 書き出し」。その最短の通しフロー
「GPX読み込み → 地図描画 → GPXエクスポート」を1本の配線チェックとして実装する。
変換ロジックの網羅検証はユニットテストの責務とし、E2E は導線の担保に徹する。

### 「モデルを変えてから横展開」への備え

後続の別モデルが引き継ぐ前提のため、**なぜそう書くか**をコメントとして厚く残す方針にした：
- 外部ネットワークの全遮断モック（許可リストではなく「localhost以外は全ブロック」）
- 動的 `<input type="file">` に対する `filechooser` イベント待受（`setInputFiles` が使えない理由）
- blob ダウンロードの `download` イベント捕捉と中身検証
- ESM (`"type": "module"`) のため `__dirname` が使えず `import.meta.url` から導出する点

### アプリ側への最小変更

エクスポートダイアログ内の要素を一意に特定する手段が無かった（地名検索など
他にも textbox が存在するため）。`Modal.tsx` に `role="dialog"` / `aria-modal="true"`
を付与し、`getByRole('dialog')` でスコープできるようにした。アクセシビリティ改善も兼ねる
最小限の変更に留めた。

### 実装中に判明した仕様

- **ルート名はファイル名由来**（GPX の `<trk><name>` ではない。`gpxParser.ts`）。
  アサーションを `getByText('sample', { exact: true })` に合わせた。
- 標高なしファイルは読み込み時に標高 API へ自動補完リクエストを送る（`useFileLoader.ts`）ため、
  フィクスチャは全点に `<ele>` を持たせて外部 API 非依存にした。

## 実行した操作

1. `npm install -D @playwright/test` / `npx playwright install chromium`
2. `Write` → `playwright.config.ts`（`webServer` に `vite dev`、Chromium のみ、CI向け retries/trace の考え方をコメント化）
3. `Write` → `tests/e2e/fixtures/sample.gpx`（東京駅周辺5点・標高/時刻付き）
4. `Write` → `tests/e2e/smoke.spec.ts`
5. `Edit` → `package.json`（`test:e2e` / `test:e2e:ui`）, `.gitignore`（レポート出力先）
6. `Edit` → `src/components/common/Modal.tsx`（`role="dialog"`）
7. `npx playwright test` を反復。`__dirname` 未定義・ルート名の思い込み・textbox 曖昧の3点を修正して緑化
8. `npm test`（ユニット19件）・`npm run build` の非退行を確認

## 応答の要点

「GPX読み込み → 地図描画 → GPXエクスポート」のスモークテスト1本を `npm run test:e2e` で
実行可能にした（2.3秒で成功）。横展開の土台として、外部ネットワークモック・filechooser・
download 検証・セレクタ選定の考え方をコメントで残した。アプリ本体の変更は `Modal.tsx` への
`role="dialog"` 付与のみ。ユニットテスト・ビルドとも非退行。
