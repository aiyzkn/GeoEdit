## Claudeの思考

### コンテキスト再構成

サマリーから「ディレクトリ構造は作成済みだが、ソースファイルは 0 件」と把握した。

### 実装戦略

一括で書いていく方針を採用。依存関係の順序：

```
型定義（types/） → ストア（stores/） → lib/（パーサー・シリアライザ・編集ロジック）
→ hooks/ → components/（layout → map → sidebar → timeline → elevation → common）
→ npm install → ビルド確認
```

### P1：プロジェクト設定ファイル

**package.json での依存選択の判断**:
- `react-leaflet` を依存に含めた → 後でビルドエラーが発生（peer deps でReact 18 を要求）
- 実装を読むと `import L from 'leaflet'` だけで済む → `react-leaflet` を削除して解決

**vite.config.ts の `__dirname` 問題**:
- ESM (`"type": "module"`) 環境では `__dirname` が存在しない
- `fileURLToPath(import.meta.url)` + `path.dirname()` で代替
- `tsconfig.node.json` に `"types": ["node"]` を追記して解決

**Tailwind CSS v4 の設定**:
- v4 では `tailwind.config.ts` は不要
- `@tailwindcss/vite` プラグインを使い、CSS に `@import "tailwindcss"` だけで動作する

### P1：型定義とストア設計の判断

**4 ストア分離の理由**:
- `routeStore`: ルートデータは大量の TrackPoint を保持するため、変更頻度が高い箇所を分離
- `editorStore`: 編集モードと Undo スタックは独立して参照されることが多い
- `mapStore`: Leaflet インスタンス（`Map`）を store に持たせることで、コンポーネント外からも地図操作が可能
- `uiStore`: テーマ・ペインサイズなど純粋な UI 状態を分離

**UndoEntry の snapshot 設計**:
`structuredClone(routes)` で深コピー。Date オブジェクトも正確に複製される。
最大 50 ステップ超過時は `shift()` で古い方から削除。

### P2：パーサー設計

**GPX パーサーの自前実装**:
外部ライブラリ（gpxparser）は `<extensions>` タグを破棄する。
ユーザー要件の「元ファイル形式で保存」を満たすため、DOMParser で自前実装した。
`_extensions` フィールドに `innerHTML` の生文字列を保存する。

**KML パーサー**:
`@tmcw/togeojson` の `kml()` で GeoJSON に変換後、GeoJSON パーサーと同じロジックを通す。
`coordTimes` プロパティを時刻として取り出す。

**GeoJSON パーサー**:
`Feature` / `FeatureCollection` / ベアジオメトリ の 3 形式すべてに対応。

### P2：MapPane の設計

**react-leaflet を使わない設計**:
`useRef<HTMLDivElement>` + `useEffect` で `L.map()` を初期化。
`RoutePolyline` は `null` を返す純粋副作用コンポーネントとして実装。
Leaflet のイベントハンドラ内では `useRouteStore.getState()` を直接呼ぶことで stale closure を回避。

**ファイルドロップ**:
地図 `div` に `onDragOver` / `onDrop` を付けることで実装。
ドロップ中は半透明の青いオーバーレイを表示してユーザーフィードバックを与える。

### P3：タイムラインの仮想スクロール

`@tanstack/react-virtual` の `useVirtualizer` を水平モードで使用。
- `horizontal: true`
- `estimateSize: () => CARD_WIDTH + CARD_GAP`（152px）
- `overscan: 10`

カードの `position: absolute` + `left: item.start` で仮想化を実現。

### P3：標高グラフ（ElevationChart）

Recharts の `AreaChart` を使用。
- `onMouseMove` でホバーポイントを `hoverPoint()` に通知 → `RoutePolyline` がマーカーを表示
- `onClick` で `selectPoint()` に通知 → タイムラインと双方向同期
- `ReferenceLine` で選択ポイントを縦線表示

### P4：GPX シリアライザの 4 モード

| モード | wpt 出力 | extensions 保持 |
|--------|---------|----------------|
| `original` | ○ | ○ |
| `original-no-wpt` | ✗ | ○ |
| `minimal` | ○ | ✗ |
| `minimal-no-wpt` | ✗ | ✗ |

### P5：編集ロジック（routeEditors.ts）

1 ファイルに主要な編集関数を集約した：
- `splitTrack` — インデックスで分割、分割点は両方に含める
- `deleteRange` — 前後 slice で区間を除去
- `reverseTrack` — `[...points].reverse()`（元配列を変更しない）
- `thinOutByDistance` — Haversine 距離の累積で判定
- `mergeTracks` — `append` / `interleave-time`（時刻ソート）
- `redistributeTime` — 傾斜別速度テーブルで時刻を再計算

### ビルドエラーの解決

1. `noUnusedLocals: true` + `noUnusedParameters: true` が厳格なため、宣言したが使わない変数を多数削除
2. `vite.config.ts` の `node:path` / `node:url` の型エラー → `@types/node` インストール + `tsconfig.node.json` に `"types": ["node"]`
3. `ElevationChart.tsx` の `totalDistKm` — 未使用のため削除
4. `editorStore.ts` の `undo()` 内で `redoStack` が未使用変数 — 分割代入を `undoStack` のみに変更

最終的にビルド成功・TypeScript エラー 0 件。
