# 015

```plaintext
次の機能を実装に追加してください。要件定義書、設計書、チェックリスト、thoughts/にも反映してください。

- タイムライン上のポイントをクリックして選択状態にすると、地図上でも対応するポイントが選択状態になる機能と、地図上のポイントをクリックして選択状態にすると、タイムライン上でも対応するポイントが選択状態になる機能

- ローカルファイルを開いた際に、標高データが含まれていない場合には、標高データを自動的に追加（補完）する機能
```

```plaintext
以下の不具合を修正してください。

- ヘッダーの「GPX / GeoJSON / KML Editor」を「GeoJSON / GPX / KML Editor」に修正。アプリ名、タイトルタグも「GeoJSON / GPX / KML Editor」に修正

- ローカルファイルを開いた際に、「標高データなし」となるのであれば、自動的に取得して標高グラフに反映させる
- ルート作成時に、地図をクリックしてポイントを追加した後、Ctrl+Zを押しても元に戻らない（ポイントが消えない）。また、Ctrl+Yでやり直しもできない
- ルート作成時、日付ピッカーは既定で現在日時（リアルタイムではなく、ページがロードされた日時）を設定しておく
```
