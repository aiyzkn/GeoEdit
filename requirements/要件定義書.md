# GeoJSON / GPX / KML エディタ 要件定義書

**バージョン**: 1.10
**作成日**: 2026-06-30
**更新日**: 2026-07-28

---

## 1. 概要

ブラウザ上で動作する GeoJSON / GPX / KML ファイルの閲覧・編集ツール。
特別なソフトのインストールは不要。インターネット接続環境で動作する。
元ファイルは読み取るだけで変更しない（非破壊編集）。

---

## 2. 技術スタック

| 項目 | 採用技術 |
|------|---------|
| 地図ライブラリ | [Leaflet](https://leafletjs.com/) |
| 地図タイル | 国土地理院タイル（標準）、他タイル切り替え可 |
| 標高データ取得 | 国土地理院標高 API (`https://cyberjapandata2.gsi.go.jp/general/dem/scripts/getelevation.php`) |
| GPX パース | [gpxparser](https://github.com/Luuka/GPXParser.js) または自前パーサー |
| KML パース | [toGeoJSON](https://github.com/mapbox/togeojson) |
| GeoJSON | ネイティブ対応（Leaflet 標準機能） |
| 動作対象ブラウザ | Chrome / Firefox / Edge（モダンブラウザ） |
| 対象デバイス | PC 優先（モバイルは最低限のレスポンシブ対応） |

## 3. UI 設計

### 3.1 画面レイアウト（2 ペイン構成）

ビデオ編集ソフトのような構成。上下方向にペインを分割し、境界をドラッグでリサイズ可能。

```
┌─────────────────────────────────────────────────┐
│  ツールバー（メニュー / 操作パネル）               │
├─────────────────────────────────────────────────┤
│                                                 │
│            メインペイン（地図）                   │
│                                                 │
├──── リサイズハンドル ────────────────────────────┤
│  [標高グラフ On/Off]                            │
│  標高グラフ（Off時は非表示）                     │
├─────────────────────────────────────────────────┤
│  タイムラインペイン（横スクロールリスト）          │
└─────────────────────────────────────────────────┘
```

- 右側のパネル（ルート・レイヤー・属性・統計）と、下側のタイムライン（標高グラフを含む）は、それぞれ完全に折りたためる。折りたたむと、その分だけ地図が広がる（両方を折りたたむと、地図がツールバーの下の画面いっぱいになる）
- 折りたたむ・開くは、ヘッダーの右端のボタン（両方）と、各ペインの見出しのボタン（折りたたむ）で行う。状態はブラウザに残る（再読み込みしても折りたたんだまま）
- 右側のパネルを折りたたんでいるときに「ポイント情報」モードに入ると、右側のパネルを開く

### 3.2 ツールバー（上部）

- アプリ名表示
- ファイル操作: 「ファイルを開く」ボタン（ダイアログ）
- 編集モード切替パネル（ボタン形式）
- Undo / Redo ボタン（アイコン表示、Ctrl+Z / Ctrl+Y のショートカットも対応）
- テーマ切り替えボタン（ライト / システム / ダーク の 3 値トグル）
- 「バージョン情報」ボタン（ℹ アイコン）: アプリバージョン・変更履歴を示すダイアログを表示
- 「使い方」ボタン（? アイコン）: ヘルプダイアログを表示
- 下側のタイムライン・右側のパネルを折りたたむ／開くボタン（3.1）

### 3.3 地図ペイン

- 画面の大部分を占める
- Leaflet 地図を表示
- 地図タイルの切り替えは右サイドバー「レイヤー」タブで行う（当初 Leaflet 標準の L.control.layers を右上に配置する想定だったが、ベース43種・オーバーレイ24種を透明度スライダー付きで扱うため専用パネル方式に変更）
- ズームコントロール（+/-）を左上に配置（地名検索ボックスと重ならないよう下にオフセット）
- ドラッグで地図移動、マウスホイールでズーム
- ルートはポリラインで表示（色は後述）
- 地図上にドラッグ＆ドロップでファイル読み込み可能
- 地図左上に地名・住所検索ボックスを表示（→ 12.2 参照）

### 3.4 タイムラインペイン（下部）

トラックポイントを時系列で横並びに表示する横スクロールリスト。

各アイテムに表示する情報:
- インデックス番号（トラック内順序）
- 時刻（`HH:mm:ss`、データなし時は `--:--:--`）
- 緯度・経度（小数点 6 桁）
- 標高（m、データなし時はブランク）
- 直前ポイントとの距離（m）
- 速度（km/h、時刻データある場合のみ）

インタラクション:
- タイムラインのアイテムをクリック → 地図上の対応ポイントにマーカーが移動・ハイライト（地図もそのポイントを中心にパン移動）
- 地図上のトラックラインをクリック → 最近傍ポイントのタイムラインアイテムへスクロール・ハイライト（双方向同期）
- 現在選択中のポイントを視覚的にハイライト（背景色変更）
- 大量ポイント（10,000 点超）でも動作する仮想スクロール（virtual scroll）で実装
- **選択中ポイントの緯度・経度編集**: 地図上に表示される選択中ポイントのマーカーはドラッグ＆ドロップで移動でき、ドロップした位置の緯度・経度がそのポイントの座標として反映される。タイムライン側では、選択中カードの緯度・経度が数値入力欄になり直接編集できる。どちらの手段で変更しても Undo 対象になる
- **横スクロール操作用のスクロールバー**: タイムライン下部に、1 点ずつ移動するボタン（◀/▶）、100 点ずつ高速移動するボタン（◀◀/▶▶）、および任意の位置へ直接ジャンプできるスライダーを備えた専用のスクロールバーを設置する。大量ポイント（10,000 点超）のファイルでも目的のポイントまで素早く移動できるようにするため
- **複数ポイント選択と一括削除**（→ 12.3 参照）

### 3.5 標高グラフ

- 「標高グラフ On/Off」ボタンでタイムライン上部に折り畳み表示
- 横軸: 距離（km）または時刻
- 縦軸: 標高（m）
- グラフ上のホバー / クリックで、対応ポイントが地図・タイムラインにハイライト
- GPS 受信エラーによる標高異常ポイントの特定に使用

### 3.6 プロパティパネル（右サイドパネルまたはモーダル）

編集モードに応じて、操作パラメータと確定ボタンを表示。右サイドパネルは「ルート」「レイヤー」「属性」「統計」の4タブ構成で、「統計」タブに選択中ルートの統計情報を表示する（→ 12.1 参照）。

## 4. ファイル操作

### 4.1 入力対応形式

| 形式 | 拡張子 | 備考 |
|------|--------|------|
| GPX | `.gpx` | 時間・標高データなしファイルにも対応 |
| KML | `.kml` | Google Map / 国土地理院地図で作成したもの |
| GeoJSON | `.geojson`, `.json` | Feature / FeatureCollection に対応 |

### 4.2 ファイル読み込み

- 地図上へのドラッグ＆ドロップ
- ファイル選択ボタン（複数ファイル同時選択可）
- 読み込み制限なし（複数ファイルの同時読み込み可）
- 読み込んだルートの一覧を「読込み済みルート」リストに表示
- 最後に読み込んだルートが編集ルートになる
- **ルート名が既存ルートと衝突する場合は読み込みを拒否せず、自動的にリネームして読み込む**（`ルート名` / `ルート名 (2)` / `ルート名 (3)` …）。リネームが発生した場合はトーストで通知する
  - 対象は次のいずれも区別しない: 1ファイル内に同名ルートが複数含まれる場合（KML/GeoJSON で同じ `name` を持つ Feature / Placemark が並ぶケース）、別ファイルに同名ルートが含まれる場合、同じファイルを再度読み込んだ場合
  - 読み込んだデータを取りこぼさないことを優先する方針（ファイル読み込みに限る。ユーザーが手入力するルート名の重複はエラーとする → 6.1 ルート作成 / 6.3 分割 / 6.8 名前変更）
- 重複するトラックポイント（同一座標・時刻）は読み込み時にスキップ
- **標高データの自動補完**: 読み込んだファイルのポイントに標高データが1つも含まれていない場合、国土地理院標高 API から自動的に取得して補完する。取得は非同期で行い、ルートの地図表示・ファイル読み込み自体をブロックしない（完了後にトーストで通知）。一部のポイントにのみ標高がある場合は対象外（既存データを上書きしない）

### 4.3 ルートの色分け

読み込んだルートには 8 色のデフォルトパレットから順に自動で色を割り当てる。

| 優先度 | 色の決定方法 |
|--------|------------|
| 1 位 | ユーザーがカラーピッカーで手動指定した色 |
| 2 位 | デフォルトパレット（読み込み順に循環割当） |

**デフォルトパレット（順に割当）**:
`#3b82f6`（青）／`#ef4444`（赤）／`#22c55e`（緑）／`#f59e0b`（橙）／
`#8b5cf6`（紫）／`#ec4899`（ピンク）／`#06b6d4`（シアン）／`#f97316`（橙赤）

**カラーピッカー操作**:
- 右サイドバーのルート一覧で、ルート名の左に表示される色スウォッチをクリック
- ブラウザ標準のカラーピッカーが開き、色を自由に変更できる
- 変更は即座に地図上のポリラインに反映される（Undo 対象外）

### 4.4 ルートの開始点・終了点マーカー

- 開始点: マゼンタ（ピンク）のドット
- 終了点: シアン（水色）のドット
- 複数トラック構成の場合、各トラックに表示

### 4.5 GPX 要素種別（ウェイポイント／ルート／トラック）

[GPX 1.1 仕様](https://www.topografix.com/gpx.asp)では、位置情報は以下の 3 種類の要素として表現される。

| 要素 | 意味 | 順序 | 時刻データ |
|------|------|------|-----------|
| `<wpt>`（ウェイポイント） | 単独の地点（POI）。互いに無関係な点の集合 | なし | 任意 |
| `<rte>`（ルート） | これから進む計画path。ナビゲーション用の経路 | あり | 通常なし（付与も可） |
| `<trk>`（トラック） | 実際に GPS 等で記録された移動経路 | あり | 通常あり |

**通常、作業軌跡（実際に移動した記録）はトラック（`<trk>`）として記録される。** 本アプリでは読込み済みルート 1 件ごとに、上記 3 種別のいずれかを表す `kind` を持つ。

#### 4.5.1 ファイルを指定した要素として開く

- ファイルを開く際、ツールバーの「開く」ボタンの左に要素種別セレクタ（トラック／ルート／ウェイポイント）を設置する
- 選択した種別が、読み込んだファイルの `kind` として適用される（デフォルト: トラック）
- ファイル自体に `<trk>` / `<rte>` / `<wpt>` のいずれが含まれているかに関わらず、ユーザーが指定した種別として強制的に解釈する
  - 例: `<trk>` を含む GPX ファイルを「ウェイポイントとして開く」と指定した場合、トラック上の各ポイントが個別のウェイポイントとして展開される
- ドラッグ＆ドロップで開く場合も、同じセレクタで選択中の種別が適用される

#### 4.5.2 読込み済みルートの要素種別を相互に変換する機能

- 読込み済みルート一覧の各行に、現在の要素種別を示すアイコンボタンを設置する
- クリックすると「トラック → ルート → ウェイポイント → トラック …」の順に種別が切り替わる
- 変換内容:
  - トラック ⇔ ルート: データはそのまま（`<trk>`/`<rte>` は同じ「順序付きpath」として扱う）で、種別タグのみ変更
  - トラック/ルート → ウェイポイント: トラック上の全ポイントを個別のウェイポイントへ変換（既存のウェイポイントがあれば統合）。地図上は接続線ではなく個別マーカーで表示する
  - ウェイポイント → トラック/ルート: ウェイポイント群を 1 本のトラック（またはルート）に変換する（順序はリスト内の並び順に従う）
- 変換操作は Undo 対象とする
- 種別に応じて地図上の表示を変える: トラック=実線、ルート=破線、ウェイポイント=個別マーカー（接続線なし）
- 種別変換後、GPX 出力時は `kind` に応じて `<trk>` / `<rte>` / `<wpt>` のいずれかとして書き出す（→ 9.2 参照）

### 5.2 オーバーレイ（複数重ね掛け可）

ベースマップの上に透過レイヤーとして重ね合わせる。チェックボックスで複数同時選択可能。
各レイヤーは `opacity` オプションで半透明を実現し、有効化したレイヤーごとにスライダー（0〜100%、5%刻み）で透明度を自由に調整できる。

> **2026-07-02 変更**: 当初は透明度ごとに「OSM 20%」「OSM 40%」のようにプリセット別の個別レイヤーとして提供していたが、透明度をスライダーで自由に調整できる以上プリセットの重複は不要と判断し、1タイルソースにつき1レイヤーへ統合した（初期透明度は0.4）。

| レイヤー名 | ベースタイル | 初期透明度（スライダーで変更可） |
|-----------|-----------|--------|
| OSM（重ね） | OpenStreetMap | 0.4 |
| 地理院タイル（重ね） | 標準地図 | 0.4 |
| 淡色地図（重ね） | 淡色地図 | 0.4 |
| 白地図（重ね） | `https://cyberjapandata.gsi.go.jp/xyz/blank/{z}/{x}/{y}.png` | 0.4 |
| 写真（シームレス、重ね） | シームレス写真 | 0.4 |
| 地質図（重ね） | 産総研地質図 | 0.4 |
| Google 標準（重ね） | Google Maps (`m`) | 0.4 |
| Google Roads（重ね） | Google 道路のみ (`h`) | 0.4 |

## 6. 編集機能

### 共通仕様

- 各編集モードは排他的に有効になる（同時に複数モードは不可）
- 確定（または実行）前にモードを変更すると、作業内容はリセットされる
- 確定操作は Undo スタックに記録される

### 6.1 ルート作成

新規ルートをゼロから作成するモード。

- 地図をクリックして通過点を順次追加
- **経路探索（2026-11 追加）**: 「経路探索」が ON（既定）のとき、通過点の間を道路に沿って自動で結ぶ
  - 道路の優先: 高速道路 ＞ 有料道路 ＞ 国道 ＞ 県道 ＞ 市区町村道 ＞ 里道。上位の道路どうしを下位の道路で結ぶ抜け道は通らない
  - 通過点は近くの道路（既定 30 m 以内）へ寄せる。Ctrl（macOS は ⌘）+ クリックの区間は直線で結ぶ
  - 分離帯のある道路・高速道路の本線は、地理院地図（標準地図）の画像に合わせて、進む向きの左側の車道の中心を通す。分離帯が描かれていない所は道路全体の中心
  - 1 区間は直線距離 100 km まで（超える区間は直線で結び、通過点を置くよう知らせる）。経路が見つからない区間も直線で結び、理由を知らせる
  - 優先の強さ・高速道路と有料道路の利用・寄せる距離・車線合わせは、利用者が設定で変えられる（ブラウザごとに保存）
  - 一方通行・右左折の規制は見ない（道路データに無い。上下線が別の線の道路とランプの向きだけ、左側通行から推定する）
  - 「経路探索」を OFF にすると、クリックした点をそのまま直線で結ぶ
- クリック地点の標高を国土地理院標高 API から自動取得
- 追加したポイントは青いラインでつなぐ（仮ルート）
- マーカー操作:
  - クリック → そのマーカーを削除
  - ドラッグ → マーカーを移動（前後の区間だけを引き直す）
  - 区間の線の上をドラッグ → その位置に通過点を差し込む（2026-11 追加）
- 作成中の操作（通過点の追加・移動・差し込み・削除）は Ctrl+Z / Ctrl+Y で取り消し・やり直しができる
- 確定時の設定:
  - ルート名（必須、既存ルートと重複不可。入力欄には既定値として「新規ルート N」（Nは読込み済みルート数+1）を設定しておく）
  - トラック名（省略可。入力欄には既定値として「新規トラック 1」を設定しておく）
  - 開始日時・終了日時（同一日付内のみ、日付をまたぐ設定は不可。開始日時の入力欄にはページ読込み時点の日時を既定値として設定しておく）
- 確定でルートが赤線に変わり、読込み済みルートリストに追加

### 6.2 部分編集

既存ルートの一部を変更するモード。

- ルート上をクリックすると、前後 300 ポイント（最大 601 ポイント）が編集マーカーに変わり青ラインを表示
- トラック総ポイント数が 601 以下の場合はトラック全体を編集範囲とする
- マーカー操作:
  - ドラッグ → マーカーを移動（始点・終点も移動可）
  - クリック → マーカーを削除（始点・終点は削除不可）
  - 青ライン上をクリック → その位置にマーカーを挿入
- 追加マーカーの標高は国土地理院 API から取得
- 追加マーカーの時刻は前後ポイント間を標高差・距離で配分した補間値
- ウェイポイントが設定されたポイントを移動・削除すると、ウェイポイントも連動
- 元の赤ラインは確定まで表示し続ける

### 6.3 分割

ルートを 2 つに分割するモード。

- ルート上をクリックして、最近傍トラックポイントに分割マーカーを設置
- 同じ分割マーカー（点）を再クリックでキャンセル
- 分割後の 2 つのルート名を設定して確定
- 分割結果: 「開始点〜マーカー」と「マーカー〜終了点」（分割点は前後**両方**のルートに含める。再結合時に経路が途切れないようにするためで、GPS編集ツールで一般的な挙動。2026-07-03 に実装に合わせて明記）
- 分割後のルート名に既存ルート名は使用不可

### 6.4 部分削除

ルートの一部区間を削除するモード。

- マーカーを 2 つ設置して削除区間を選択、確定で削除
- マーカーの設置順序は問わない
- 再クリックでマーカーをキャンセル
- 始点〜マーカー間、またはマーカー〜終点の削除はマーカー 1 つで可

### 6.5 結合

2 つのルートを結合するモード。

- ルートを 2 つクリックして選択し、結合方法を選んで確定
- 再クリックで選択をキャンセル
- 結合方法:

| 方法 | 説明 | 時間データ要否 |
|------|------|-------------|
| トラックを統合して結合 | 2 ルートのトラックをすべて統合し時系列に結合 | 必要 |
| トラックを時系列で結合 | トラック単位を保持しつつ時系列に結合 | 必要 |
| トラックの単純接続 | トラックを単純連結（順序を保持） | 不要 |

- ルート内の複数トラックを 1 つに統合する場合: ルートを 1 つだけ選択し「トラックを統合して結合」を使用

### 6.6 間引き

トラックポイントを指定間隔（m）で間引くモード。

- 間引き間隔をメートル単位で入力して実行
- 間隔はポイント間距離の積算で判断（若干の誤差あり）
- トラック終端およびウェイポイント付きポイントは指定間隔より短くなる場合あり

### 6.7 時間変更

各トラックポイントの時刻を再設定するモード。

**一括再計算モード**:
- 設定項目: 日付・開始時刻・終了時刻
- 時間配分は始点〜終点の距離と標高差に応じて計算
- 日付をまたいだ設定は不可

**シフトモード**:
- 日付のみ・開始時刻のみ・または両方を指定してすべてのポイントをシフト
- シフト後の秒の桁はシフト前と同じ値を維持

### 6.8 名前変更

ルート名とトラック名を変更するモード。

- ルート名（1 行テキストボックス）: 全角・半角可、ファイル名として使えない文字は保存時に `_` へ自動置換
- トラック名（複数行テキストボックス）: トラック数と同じ行数で記述
  - 書式: `<name>名前<number>番号`（トラック名・番号ともブランク可）

### 6.9 ウェイポイント編集

ウェイポイントを追加・編集・削除するモード。

- 編集可能項目: 名前（`name`）、コメント（`cmt`）、説明（`desc`）
- 追加: ルート上をクリック → 最近傍トラックポイントにウェイポイントを追加
- 削除: ウェイポイントマーカーを右クリック
- 追加・削除はクリック時点で即時反映（モード変更でもキャンセルされない）
- 部分編集・部分削除モードで、ウェイポイント付きポイントを操作するとウェイポイントも連動

### 6.10 逆ルート

ルートの始点と終点を入れ替えるモード。

- 確定後は時刻データが失われる（必要に応じて「時間変更」で再設定）

### 6.11 標高置換

国土地理院標高 API のデータでトラックポイントの標高を上書きするモード。

- データソース: DEM5A（約 5m メッシュ、優先）/ DEM10B（約 10m メッシュ）
- 海・湖の橋上など API にデータがない場所: デフォルトで標高代替値を使用
- ラジオボタンで代替値を使わない設定も可（その場合は標高値をブランクとする）
- GPS 受信エラーによる標高異常の修正や、標高データのない KML ファイルへの補完に使用

| 項目 | 内容 |

## 8. Undo / Redo

- 対象: すべての編集確定操作（ルート作成・部分編集・分割・結合・削除・時間変更・名前変更・ウェイポイント操作・標高置換など）
- ショートカット: Undo = `Ctrl+Z`、Redo = `Ctrl+Y`（Mac は `Cmd+Z` / `Cmd+Shift+Z`）
- そのほかのキー: `Enter` = いまのモードの確定・実行（入力欄・ボタンにフォーカスがあるときは、その欄・ボタンの動き）、`Escape` = モードの取り消し（ダイアログが開いているときは、ダイアログを閉じる）
- ツールバーに Undo / Redo ボタンを設置（操作不可時はグレーアウト）
- Undo 可能な上限回数: 50 ステップ（超過した場合は古いものから削除）

## 9. ファイル出力

読み込んだルートを編集後にファイルとして保存する機能。

### 9.1 対応エクスポート形式

| 形式 | 説明 |
|------|------|
| GPX | 標準 GPX 形式。緯度経度・標高・時刻・ウェイポイントを含む |
| GeoJSON | GeoJSON FeatureCollection 形式 |
| KML | KML 形式（Google Earth / Google Map 互換） |

### 9.2 出力オプション（GPX）

- **元ファイル形式で保存**: 付加情報（heartrate 等の extensions タグ）を保持
- **最小サイズで保存**: trkpt を緯度経度・標高・時刻のみに削減してファイルサイズを削減
- **ウェイポイント除去オプション**: 上記それぞれに「wpt 無」の選択肢を追加
- **要素種別に応じた出力**（→ 4.5 参照）: ルートの `kind` が「トラック」なら `<trk>`、「ルート」なら `<rte>`、「ウェイポイント」なら `<wpt>` として出力する。「ウェイポイント」種別のルートは本体データがウェイポイントそのものであるため、「wpt 無」オプションを選んでも常に出力される

### 9.3 出力操作

- 出力対象のルートを選択（ヘッダーの「出力」、またはルート一覧の行のエクスポートボタンで、エクスポートダイアログを開く）
- デフォルトファイル名: `{元ファイル名}_ed.{拡張子}`
- ファイル名は自由に変更可能
- 「保存」ボタンでブラウザのダウンロードフォルダに出力
- 「コピー」ボタンで、選んでいる形式・オプションの文字列をクリップボードへコピー（保存と同じ中身。2 MB を超えるときは確認する）

## 11. バージョン管理

### 11.1 バージョン番号体系

セマンティックバージョニング（`MAJOR.MINOR.PATCH`）を採用する。

| 桁 | 意味 | 例 |

## 12. 統計・検索・タイムライン一括操作機能

参考サイトにはない独自の追加機能として、以下を実装する。

### 12.1 統計情報パネル

選択中の編集ルートについて以下の統計値を右サイドバーの「統計」タブに表示する（全トラックの合計値）:

- 総距離（km）
- 累積標高差: 登り（m）/ 下り（m）
- 最高標高 / 最低標高（m）
- 総所要時間（時刻データある場合のみ）
- 平均速度 / 最高速度（km/h、時刻データある場合のみ）
- トラックポイント総数

### 12.2 地名検索・ジャンプ

- 地図左上に地名・住所検索ボックスを表示
- 国土地理院ジオコーディング API（`msearch.gsi.go.jp/address-search/AddressSearch`）を使った検索
- 検索結果一覧から選択すると、その場所に地図をジャンプ（ズームレベル15）

### 12.3 複数ポイントのタイムライン選択と一括削除

- タイムライン上で `Shift+クリック`（範囲選択）/ `Ctrl+クリック`・`Cmd+クリック`（個別選択の追加・解除）による複数ポイント選択
- 選択中はカードを強調表示し、選択件数と「選択したポイントを削除」ボタンを表示
- 選択したポイントを一括削除（Undo 対象）。トラック上の全ポイントを選択した場合は削除不可（最低 1 点を残す）
- ルートまたはトラックを切り替えると選択状態はリセットされる

## 13. 制約・考慮事項

- インターネット接続が必要（地図タイル・標高 API へのアクセスに使用）
- 日付をまたぐ時間設定は不可（「時間変更」「ルート作成」ともに）
- 部分編集の編集範囲はトラック単位で最大 601 ポイント
- ルート名は読込み済みルート間で一意であること（ファイル読み込み時の衝突は自動リネームで一意化する → 4.2、編集操作での手入力による衝突はエラーとして拒否する）
- ウェイポイントの編集可能項目は name / cmt / desc のみ（その他の情報は読み込み時に破棄）
- 大量ポイント（10,000 点超）のファイルではタイムラインに仮想スクロールを使用して描画コストを抑制
- Leaflet 地図上に多数のマーカーを同時表示する場合は `L.DivIcon` の軽量マーカーを使用してパフォーマンスを確保
- 標高 API はリクエスト過多にならないよう、連続取得時はバッチ処理・間引きを行う

## 14. 画面遷移・操作フロー（概要）

```
起動
 └─ 初期画面（地図のみ表示）
     ├─ ファイル読み込み（D&D / ファイル選択）
     │    └─ ルートが地図に表示 → 読込み済みリストに追加
     │         └─ 編集モード選択
     │              ├─ ルート作成 → クリックでポイント追加 → 確定
     │              ├─ 部分編集 → ポイント操作 → 確定
     │              ├─ 分割 → マーカー設置 → ルート名入力 → 確定
     │              ├─ 部分削除 → マーカー 2 点設置 → 確定
     │              ├─ 結合 → ルート 2 本選択 → 結合方法選択 → 確定
     │              ├─ 時間変更 → 日付・時刻入力 → 実行
     │              ├─ 名前変更 → 名前入力 → 確定
     │              ├─ ウェイポイント → ライン上クリックで追加 / 右クリックで削除
     │              ├─ 逆ルート → 確定
     │              ├─ 標高置換 → 確定
     │              ├─ 間引き → 間隔入力 → 実行
     │              └─ ポイント情報 → クリックで情報表示 → 個別編集
     └─ ファイル出力 → 形式・オプション選択 → 保存
```

## 15. 非機能要件

| 項目 | 内容 |
|------|------|
| 対応ブラウザ | Chrome / Firefox / Edge の最新版 |
| モバイル対応 | PC 優先。スマートフォン・タブレットでも最低限表示・操作できる程度のレスポンシブ対応 |
