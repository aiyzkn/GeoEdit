# 経路探索の試作（スパイク）

[経路探索詳細設計書.md](../../経路探索詳細設計書.md) の数値を測ったスクリプト。**アプリには含めない**（ビルド・テストの対象外）。数値を測り直す・重みを調整するときに使う。

## 使い方

```sh
cd designs/spike/routing
npm init -y && npm i @mapbox/vector-tile@1.3.1 pbf@3.2.1 pngjs@7   # ここだけの依存（リポジトリにはコミットしない）
node s1.mjs nihonbashi 139.774 35.684 1
```

取得したタイルは `cache/` に保存する（コミットしない）。地理院のサーバーへ実際に要求するので、範囲を広げすぎない。

| ファイル | 内容 | 引数 |
|---|---|---|
| `lib.mjs` | タイルの取得（ディスクにキャッシュ）・座標の変換 | |
| `graph.mjs` | タイルを切る・縫い合わせる・グラフにする・階級を決める | |
| `search.mjs` | 探索。**採用した規則は `{ mode: 'rim', freeRadius: 0, floor: 2 }`**。指定なしは、方針の設計書の最初の案（相による規則）で、比較用 | |
| `s1.mjs` | 属性の分布・座標の範囲・境界の端点 | 名前 経度 緯度 半径（タイル数） |
| `s2.mjs` | 切って縫い合わせたグラフの連結成分・端点を共有しない交差 | 同上 |
| `s3.mjs` | 最短・重みだけ・谷の罰則つきの経路の比較 | 名前 経度 緯度 半径 階級（0 = すべて） 組数 乱数の種 |
| `s4.mjs` | 規則ごとの、行きと帰りの対称性 | 名前 経度 緯度 半径 組数 種 |
| `s5.mjs` | ズームごとのタイルの性質と、z14 との形の差 | 名前 経度 緯度 |
| `s6.mjs` | 低いズームのつながり方 | 名前 経度 緯度 ズーム 半径 |
| `s7.mjs` | 最適な経路が、始点–終点の線分からどれだけ離れるか | 名前 経度 緯度 半径 組数 種 |
| `offset.ts` | 中心線と、標準地図の画像の道路中心とのズレ（アプリのマップマッチングで測る。詳細設計書 §12）。Node 22.6 以上（TypeScript をそのまま動かす。アプリの `src/` を読み込む） | 名前 経度 緯度 半径 1 ズームあたりの点数 種 |
| `render.ts` | 標準地図の画像（z17）に中心線を赤で重ねた PNG を書き出す（ズレの目視） | 緯度 経度 出力先 |
| `s8.mjs` | 2 段階の探索（z12 → z14 の回廊）と、全体での最適との比較。環境変数 `ALT=1`（高速なしの経路も回廊に入れる）・`BR=1`（行き止まりの橋渡しを同じ成分にも行う）が、採用した設定 | 名前 経度 緯度 半径 組数 種 最短の直線距離(km) 回廊の幅(m) 端の半径(m) |

出典: 国土地理院ベクトルタイル提供実験。
