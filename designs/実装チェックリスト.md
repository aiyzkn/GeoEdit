## 優先度の定義

| 優先度 | 基準 |
|--------|------|
| **P1** | 他のすべての実装の前提となる基盤。これなしに次のフェーズを開始できない |
| **P2** | ファイルを読み込んで地図に表示できる最小動作状態を実現する |
| **P3** | 編集前の閲覧・情報確認機能。Undo/Redo基盤もここに含む |
| **P4** | 編集結果をファイルに保存できる。編集と出力は対になる |
| **P5** | 最もよく使われるコア編集操作（ルート作成・部分編集・分割・削除・結合） |
| **P6** | 追加の編集操作（時間変更・名前変更・ウェイポイント・逆ルート・標高置換・間引き） |
| **P7** | タイルレイヤーの完全対応・ダークモードタイル対応 |
| **P8** | UI の仕上げ・追加提案機能・デプロイ設定 |
